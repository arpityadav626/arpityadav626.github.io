## 🚀 Flagship Engineering Projects

### 01. Smart Helmet — IoT Road Safety & Accident Mitigation System
- **Category:** Hardware IoT & Embedded Systems
- **Platform:** ESP32, MQ-3 Alcohol Sensor, 6-Axis MPU6050 Accelerometer/Gyro, 433MHz RF, SIM800L GSM/GPS
- **Context:** **Smart India Hackathon (SIH 2026 Problem SIH26220)** Prototype Showcase
- **Key Features:** Two-wheeler ignition-interlock enforcing mandatory helmet wear compliance and zero blood-alcohol concentration (BAC) prior to enabling vehicle ignition. Automated crash SOS dispatch with real-time GPS coordinates via GSM cellular network.

### 02. SAFETY-FI 96X — Smart Kitchen Safety & Industrial IoT Automation
- **Category:** Embedded IoT + 3D Digital Twin
- **Platform:** Arduino Uno, Embedded C++, Python (FastAPI), Three.js, MQ-2 Gas & Optical IR Flame Sensors
- **Key Features:** Deterministic Finite State Machine (FSM) mitigating LPG gas leaks (>400 PPM) and flame radiation with automatic exhaust and sprinkler relay interlocks. Real-time Three.js 3D cooktop digital twin dashboard with Python serial telemetry.

### 03. CHRONOFACT 2.0 — Digital Forensic Investigation Workbench
- **Category:** Digital Forensics & Verifiable Legal Reasoning
- **Platform:** Python, FastAPI, SQLite FTS5, NIST SHA-256 / SHA3-256, AST
- **Legal Compliance:** Compliant with **Section 63(4) of Bharatiya Sakshya Adhiniyam (BSA), 2023**
- **Key Features:** Dual-hash cryptographic Merkle tree engine, James Allen's temporal interval algebra, deterministic inconsistency radar, and mechanical AST byte-span citation verification gate eliminating AI hallucinations.

### 04. Developer Portfolio Architecture (`arpity.me`)
- **Category:** Modern Semantic Frontend & Audio Engineering
- **Platform:** Semantic HTML5, CSS3, Procedural Web Audio API, Zero-Framework Architecture
- **Key Features:** Zero external audio files—procedural audio synthesis via native JavaScript `AudioContext` with custom brickwall dynamics compression limiter. 100% fluid responsive breakpoints across mobile, tablet, and desktop viewports.

### 05. AI Hub (`arpit-fun.web.app`) — 3D Discovery Station & Media Suite
- **Category:** Full-Stack AI & 3D Web Application
- **Platform:** React 19, TypeScript, Three.js, Tailwind CSS v4, Google Cloud & GitHub Actions CI/CD
- **Key Features:** 3D periodic helical navigation system sustaining 60 FPS via custom GLSL shaders with depth-of-field disc blur and Retina supersampling. Multi-provider LLM processing (Gemini, Groq Llama-3) with local offline heuristic NLP fallback. Integrated 4K cinema player, 70K+ Project Gutenberg eBook reader, and ambient lofi stream.
