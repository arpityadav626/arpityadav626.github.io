# Arpit's Creative Lab & Experimental Studio ✦

A completely independent, standalone website showcasing interactive browser experiments, procedural Web Audio synthesizer engines, 3D living canvases, and creative software engineering.

## 🚀 Independent Architecture
This website is 100% standalone and separate from the main engineering portfolio (`arpity.me`):
- **Entry point:** `index.html`
- **Styles:** `style.css`
- **Engine:** `script.js`
- **Self-contained Assets:** `assets/` (Peeps crowd sprites, Sylva 3D scene, icons, etc.)

## 🌟 Restored Modules
1. **Never Walk Alone (Crowd Canvas):** Pure HTML5 Canvas crowd simulation with click-to-spawn walkers, pace control, and density telemetry.
2. **Cozy SFX Studio:** 0 KB procedural Web Audio synthesizer soundboard, 6-key pentatonic keyboard, and real-time frequency visualizer.
3. **Sylva Living World:** 3D procedural living moss ecosystem (WebGL / Three.js).
4. **Skiper 19 Kinetic Stroke:** Parametric SVG gradient stroke animation with interactive scrub control.
5. **arpit.config.ts:** Interactive terminal configuration card with real UTC clock.
6. **Namaste Preloader:** Replayable Dennis Snellenberg organic liquid SVG curtain morph.
7. **Developer Portfolio Engine (Project 04):** Restored architectural showcase.
8. **Algorithmic Core:** Problem-solving hub for LeetCode & GFG.

## 📤 Upload Studio
- Click **"+ Upload Creation"** to add new creative experiments directly from your browser.
- Data is saved persistently in `localStorage`.
- Includes **Export JSON** and **Import JSON** buttons to back up or share your creations.

## 🌐 How to Run or Deploy
- **Locally:** Simply open `index.html` in any modern web browser or run `npx serve .` / `python -m http.server`.
- **Deploy:** Ready for instant 1-click deployment on Vercel, Netlify, GitHub Pages, or as a subdomain (e.g. `lab.arpity.me`).
- **Linking with Portfolio:** In your main portfolio, simply link to this website using an external hyperlink (`<a href="https://your-creative-site-url..." target="_blank">Creative Lab ↗</a>`).
